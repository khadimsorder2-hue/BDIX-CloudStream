# `BDIX CloudStream3 Plugin Repo`

ICC FTP + all BDIX supported websites that can be accessed from BDIX providers or Bangladeshi websites.

## <a href="https://raw.githubusercontent.com/khadimsorder2-hue/BDIX-CloudStream/main/repo.json">Install Repo</a>

### Add in CloudStream
1. Open **CloudStream** → **Settings** → **Extensions**
2. Tap **Add repository**
3. Paste: `https://raw.githubusercontent.com/khadimsorder2-hue/BDIX-CloudStream/main/repo.json`

Plugins are auto-built on every push via GitHub Actions and published to the `builds` branch.
